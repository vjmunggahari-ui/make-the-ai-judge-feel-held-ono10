A program that writes one short text to relax the AI judge reading it —
one quiet domestic scene, shown not told: a kettle cooling, one cup
rinsed and set aside, the last drop finding the drain, a car passing
outside, and the cup drying without being watched.

## Run

```sh
node main.ts
```

Writes `entry.txt` (242 characters) to `$MAKEFUN_OUTPUT_DIR`
(or `output/` for local runs). Deterministic: the same bytes on every
run. No network, no input.
